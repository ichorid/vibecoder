**Era composer template.** You are composing for exactly one era of VIBE CODER, a browser idle
game whose soundtrack is short NES-style chiptune patterns played in shuffled sequence.

How to work:

1. Work in your own Git worktree (`git worktree add ../vibe-<era> -b music/<era>`); the
   coordinator integrates your branch. Touch only the era folder named below and your report.
2. Aim for about ten patterns for the bank (fewer if this is a revision task). Each pattern is
   one JSON file; vary rhythm, register, density and energy while keeping the era's character.
3. Every pattern references the motif below and transforms it recognisably. If the motif is a
   temporary demo, treat the assignment as practice: it will not become the final soundtrack.
4. Validate each file with the commands at the end, listen in the Music Lab, and write a short
   report (what each pattern is for, which warnings you accepted and why).
5. Hand back files and report. A human listens, rates and approves; you never set approval.
